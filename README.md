# 잃어버린 노래

3D 오버월드를 탐험해 잠든 악기점에 들어가고, 숨은 음표와 음악 미니게임을 해결해
분리된 악기 스템을 하나의 곡으로 완성하는 브라우저 게임입니다.

## 플레이 방법

1. 시작 버튼으로 오디오를 활성화합니다.
2. 흰 종이 오버월드에서 클릭 또는 드래그해 캐릭터를 움직입니다.
3. 음악이 커지는 방향을 따라 빛나는 입구로 이동합니다.
4. 2D 악기점에서 드래그로 화면을 이동하고, 휠 또는 핀치로 확대합니다.
5. 숨은 음표 4개를 찾고 미니게임 3개를 완료합니다.
6. 음표마다 고유한 스템 또는 믹스 변화가 켜지며, 7개를 모으면 노래가 완성됩니다.

모바일에서는 가로·세로 화면을 모두 지원합니다. 진행 상황과 음소거 설정은 브라우저에 자동 저장됩니다.

## 미니게임

- 앰프 조율: 움직이는 커서를 목표 구간에서 세 번 멈춥니다.
- 페달 리듬: 현재 곡의 BPM에 맞춰 16번 탭하고 정확도 70% 이상을 달성합니다.
- CRT 멜로디: 네 버튼의 발광 순서를 세 라운드 동안 기억해 재현합니다.

## 기술 스택

- Vite + TypeScript strict
- Three.js: 3D 오버월드와 OrthographicCamera 기반 2D 지역
- GSAP: 씬 전환과 완료 연출
- Web Audio API: 동기 스템 재생, 필터와 볼륨 자동화, 코드 생성 플레이스홀더
- DOM + CSS: HUD, 로딩, 미니게임, 완료 연출

React나 별도 오디오 라이브러리 없이 구현했습니다. 모든 외부 에셋 경로와 지역 음악 데이터는
`src/core/assetManifest.ts`에 모여 있으며, 누락된 에셋은 코드 생성 플레이스홀더로 대체됩니다.

## 실행

```powershell
npm.cmd install
npm.cmd run dev
```

프로덕션 빌드:

```powershell
npm.cmd run build
```

## 배포

`main` 브랜치에 푸시하면 GitHub Actions가 Vite 빌드를 실행하고 GitHub Pages에 `dist/`를 자동 배포합니다.
배포 주소는 `https://sukh115.github.io/codexBrowserGame/`입니다. 저장소의 Pages 설정에서 Source를
`GitHub Actions`로 선택해야 합니다.

## 프로젝트 구조

```text
src/
  audio/       Web Audio 스템과 효과음
  core/        엔진, 입력, 상태, 에셋 manifest
  scenes/      3D 오버월드와 2D 지역·미니게임
  ui/          로딩, HUD, 완료 연출
public/assets/ 실제 교체 가능한 디자인·사운드 에셋
```

## 에셋 교체

- 캐릭터와 배경, 스템 경로는 `src/core/assetManifest.ts`에서 변경합니다.
- 실제 스템은 같은 BPM, 길이, 시작점으로 내보낸 파일이어야 합니다.
- 악기점 배경의 음표·미니게임 위치는 UV 좌표로 관리되어 이미지 해상도와 독립적입니다.
- 상세 제작 규격은 `ASSET_SPECS.md`를 따릅니다.

## Codex 활용

기획 문서를 고정 규약으로 두고 기능 단위로 구현, strict 타입 검사, 프로덕션 빌드와 Git 커밋을
반복했습니다. 에셋이 도착하기 전에도 전체 플레이 흐름을 검증할 수 있도록 오디오·텍스처·모델
플레이스홀더를 코드로 먼저 구축했습니다.

## 배치 수정 방법

1. 게임 주소에 `?debug=1`을 붙여 지역을 엽니다.
2. 원하는 배경 위치를 `Shift+클릭`해 콘솔의 UV JSON 스니펫을 복사합니다.
3. 해당 값을 `src/regionData/musicShop.ts` 또는 `neonForest.ts`에 붙여넣습니다.
